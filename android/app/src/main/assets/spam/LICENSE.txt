This classifier adapts two public datasets into TF-IDF features and logistic
regression weights. It does not contain the user's private SMS. The trained
model and its preprocessing differ from the original datasets. See the bundled
provenance.json for pinned inputs, training parameters and evaluation.

1. Ferdila Rahmi and Yudi Wibisono (2016), Aplikasi SMS Spam Filtering pada
   Android menggunakan Naive Bayes, Unpublished manuscript.
   SMS Spam Bahasa Indonesia, version 1.0, August 2018.
   Published by Yudi Wibisono with the author's permission:
   https://yudiwbs.wordpress.com/2018/08/05/dataset-klasifikasi-bahasa-indonesia-sms-spam-klasifikasi-teks-dengan-scikit-learn/
   CC BY-SA 4.0, as stated in penjelasan.txt inside the original dataset zip.
   https://creativecommons.org/licenses/by-sa/4.0/

2. Tiago Almeida and Jos Hidalgo (2011), SMS Spam Collection [Dataset].
   UCI Machine Learning Repository. https://doi.org/10.24432/C5CC84
   CC BY 4.0, as stated by the UCI repository.
   https://creativecommons.org/licenses/by/4.0/

The model uses a deduplicated subset for training; validation and test messages
are kept out of training, with similar message templates grouped together.
Model scores and evaluation results do not guarantee future detection rates.
